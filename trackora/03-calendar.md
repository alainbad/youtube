# 3. 90-day content calendar

**Cadence:** 1 long video/week (Tuesday) + 2 Shorts/week cut from it (Thursday, Saturday).
Assumes ~6–8 hrs/week. If you have less, drop Shorts, never the long video.

**Search-first** = exact phrases people type; wins slowly but compounds.
**Browse-first** = curiosity/story; can spike but is less predictable.

## Why this order builds authority
- **Weeks 1–4:** searchable basics. They bring the first viewers and are the videos every later one links back to.
- **Weeks 5–8:** test formats. One story video, one "I calculated it" video. See which holds viewers longer.
- **Weeks 9–12:** double down on whatever won, and finish with landed cost, the topic that sells Pro/Business.

Each video's existing blog post on track-ora.com (`/blog/...`) is the script's research source and the link in the description.

## Checkpoints

| Day | Keep going if… | Change if… |
|---|---|---|
| 30 | Avg view duration ≥ 40% on search videos; at least some clicks to track-ora.com | AVD < 30% → hooks are failing; rewrite first 15s |
| 60 | One format clearly beats the other on AVD + subs/video | Click-through rate (CTR) < 3% across the board → thumbnails/titles, not content, are the problem |
| 90 | Signups attributed to YouTube (UTM links) > 0 | Views but zero signups → the tool demo is missing or the CTA is wrong |

**Tracking signups:** every link uses `?utm_source=youtube&utm_campaign=wk01` etc. so signups can be traced to a video.
